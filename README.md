# 🍯 খাঁটি মধু ও হানি নাট ল্যান্ডিং পেজ + Admin Panel

## কীভাবে কাজ করে
- **ওয়েবসাইটের সব কনটেন্ট/দাম/রং/ছবি/সেকশন** `js/config.js` ফাইলে থাকে।
- `admin.html` খুলে পাসওয়ার্ড দিয়ে লগইন করুন। **ডানদিকের মেনুতে** প্রতিটি সেকশনের আলাদা পেজ আছে (মোবাইলে ☰ মেনু চাপুন)।
- পরিবর্তন শেষে **⬇️ আপডেট ডাউনলোড** → প্রজেক্টে বসান → **commit → push** → Vercel ডিপ্লয় করবে।
- অর্ডার, ভিজিটর অ্যাক্টিভিটি ও Pixel ইভেন্ট আপনার **গুগল শিটে** যায়।

## Admin Panel এ যা আছে (ডানদিকের মেনু)
- **প্রতিটি সেকশন আলাদা পেজে**: টপ হেডিং, ভিডিও, নোটিশ, অর্ডার বাটন, বিশেষত্ব, প্রোডাক্ট স্লাইডার (টাইটেল+ছবি), কাস্টমারদের মতামত, ল্যাব রিপোর্ট ও ডকুমেন্টস, বিশেষ ছাড় (টাইটেল+কনটেন্ট), স্ট্রিপ, অর্ডার ফর্ম, ফুটার
- প্রতিটি সেকশনে **দেখান/লুকান সুইচ** ও ↑↓ ক্রম পরিবর্তন
- **＋ নতুন সেকশন**: টাইটেল, সাবটাইটেল, লেখা, ছবি (বড় ছবি / স্লাইডার / গ্রিড / কার্ড), বাটন (অর্ডার/লিংক), ব্যাকগ্রাউন্ড ও রং
- **পণ্য ও দাম**, **রং ও থিম** (৬টি তৈরি থিম + আলাদা আলাদা রং), **সাধারণ সেটিংস**
- **Google Sheet ও API**: শিটের লিংক দিলে Code.gs তৈরি হয় (কপি/ডাউনলোড), আর API (/exec) লিংক বসানোর ঘর
- **ট্র্যাকিং ও ফ্রড**: Facebook Pixel ID, ভিজিটর ট্র্যাকিং চালু/বন্ধ ও শতাংশ, ফ্রড এলার্টের সময় (ডিফল্ট ২ মিনিট)
- **লাইভ প্রিভিউ** (ডেস্কটপে পাশে দেখায়), ব্যাকআপ, ছবি বেছে নেওয়ার বাটন (কম্প্রেস হয়ে `site-update.zip` এ আসে)

## গুগল শিট সেটআপ (একবারই)
1. Admin ➔ **Google Sheet ও API** ➔ শিটের লিংক ও ওয়েবসাইটের লিংক দিন ➔ **Code.gs কপি করুন**
2. গুগল শিট ➔ **Extensions ➔ Apps Script** ➔ আগের কোড মুছে পেস্ট ➔ Save
3. `setupAll` সিলেক্ট করে ▶ Run (Permission দিন) – এই ট্যাবগুলো নিজে তৈরি হবে:
   **Orders · User Activity · Pixel Events · Report · Dashboard**
4. **Deploy ➔ New deployment ➔ Web app** (Execute as: Me, Access: Anyone) ➔ /exec লিংক Admin এর API ঘরে বসান ➔ ডাউনলোড ➔ push
5. পরে Code.gs বদলালে: **Deploy ➔ Manage deployments ➔ ✏️ ➔ New version ➔ Deploy** (লিংক একই থাকে)

## গতি ও একসাথে অনেক ভিজিটর
- ওয়েবসাইট স্ট্যাটিক (Vercel CDN)। প্রথম লোড মাত্র ~২৭ KB (gzip); ছবি/ভিডিও পরে লোড হয়।
- ভিজিটর আসলে গুগল স্ক্রিপ্ট কল হয় না। ট্র্যাকিং ভিজিটর চলে যাওয়ার সময় একবারই যায়।
- অর্ডার সার্ভারে লাইনে দাঁড়িয়ে একটি একটি করে সেভ হয়। ব্যস্ত থাকলে ওয়েবসাইট নিজে থেকে একই অর্ডার আবার পাঠায় (ডুপ্লিকেট হয় না)।
- একই নাম্বারে ২ মিনিটের মধ্যে আবার অর্ডার করলে ফ্রড এলার্ট; অন্য নাম্বারে সমস্যা নেই।

## নিরাপত্তা
- অ্যাডমিন পাসওয়ার্ড ব্রাউজারে যাচাই হয় (ফাইলে শুধু হ্যাশ)। কিছু লাইভ হয় শুধু আপনার commit/push এর পর।
- শিটের ডেমো কার্ড (অর্ডার ফর্ম সেকশনে) শিটের লিংক সবাইকে দেখায় – কাস্টমারের শিটের জন্য এটি বন্ধ রাখুন।
- গুগল শিটের লিংক ওয়েবসাইটের ফাইলে যায় না; Code.gs তৈরির জন্য শুধু আপনার ডিভাইসে থাকে।
